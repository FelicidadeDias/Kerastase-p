# Kérastase Paris — Catálogo digital

Demonstração de uma loja online/catalogo de produtos capilares, com pesquisa, filtros por categoria e chamadas para encomenda pelo WhatsApp.

## Antes de publicar comercialmente

1. Substituir os produtos ilustrativos pelas referências reais da loja.
2. Inserir fotografias autorizadas, nomes, descrições e preços confirmados.
3. Definir o número oficial de WhatsApp em `WHATSAPP_NUMBER` no fim de `index.html` (apenas dígitos, incluindo indicativo do país).
4. Confirmar morada, horários, condições de entrega e meios de pagamento.
5. Rever a utilização do nome e identidade visual: esta demonstração não afirma ser o website oficial da marca Kérastase nem confirma qualquer estatuto de revendedor autorizado.

## Publicação

O ficheiro `index.html` é estático e pode ser publicado no GitHub Pages a partir da branch `main`, usando a raiz do repositório.
